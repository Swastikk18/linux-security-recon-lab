# Linux Fundamentals

## Objective

To understand basic Linux commands, directory navigation, file management, permissions, users, groups, and processes.

## Topics to Practice

- Navigating files and directories
- Listing files and viewing file contents
- Creating directories and files
- Understanding file permissions
- Identifying users and groups
- Viewing running processes

## Practical Exercises

Practical commands, observations, screenshots, and learning outcomes will be documented here after testing them in the Kali Linux environment.

## Safety Note

Commands that modify files, permissions, or system settings will be tested carefully in the lab environment.
