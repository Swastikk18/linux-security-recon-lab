# Linux, Security Tools & Reconnaissance Lab

## About This Project

This repository documents my practical learning in Linux fundamentals, cybersecurity tools, network reconnaissance, and security analysis as part of my cybersecurity internship.

## Objectives

- Learn Linux commands, file permissions, users, groups, and processes.
- Understand passive and active reconnaissance.
- Explore DNS and network enumeration.
- Practice network scanning using Nmap.
- Learn packet analysis using Wireshark.
- Explore web security testing using Burp Suite and OWASP ZAP.
- Build and document a controlled cybersecurity lab.

## Tools Used

- Kali Linux
- Linux Terminal
- Nmap
- Wireshark
- Burp Suite
- OWASP ZAP
- Git and GitHub

## Practical Modules

1. Linux Fundamentals
2. Passive and Active Reconnaissance
3. DNS and Network Enumeration
4. Security Tool Exploration
5. Controlled Lab Setup and Findings

## Safety and Authorization

All security testing will be performed only on my own machine, authorized targets, or intentionally vulnerable lab environments.

## Progress

This repository will be updated as I complete each practical exercise and document the actual results.

## Conclusion

The objective of this project is to develop practical skills in Linux, networking, reconnaissance, and cybersecurity analysis.
